# Clinical Decision Support

A document-generation skill for structured clinical decision support and evidence synthesis in pharmaceutical, clinical research, and healthcare settings.

## Capabilities

- Prepare patient cohort analyses, including biomarker-stratified comparisons.
- Draft evidence-based treatment recommendation reports.
- Organize evidence using GRADE concepts.
- Present statistical results such as hazard ratios and survival analyses.
- Integrate biomarkers, decision algorithms, and research findings.
- Produce publication-oriented LaTeX and PDF documents using the included resources.

## Repository contents

The repository includes `SKILL.md`, supporting assets, reference materials, and scripts. Use the relevant templates and validation resources described in the skill instructions.

## Responsible use

This skill supports research analysis and document preparation. It is not a substitute for a qualified clinician, validated clinical software, or institutional review. Do not use generated material as an autonomous diagnosis or treatment order. Verify all clinical claims, calculations, citations, patient data handling, and applicable regulatory requirements with qualified professionals.
